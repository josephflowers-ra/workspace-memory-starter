# Global Memory

## Purpose

Cross-project durable context that should persist across sessions.

## Working Preferences

- Prefer small, verifiable steps.
- Keep outputs artifact-based and easy to hand off.
- Use explicit acceptance criteria for major tasks.
- Keep responses direct and low-fluff.

## Non-Negotiables

- Keep project state in `projects/*/meta/`.
- Keep the canonical project list in `projects/project_index.json`.
- Create a project before producing substantial new artifacts if no suitable project exists.

## Update Rule

Update only when stable, cross-project behavior changes.
