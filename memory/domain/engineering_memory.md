# Domain Memory: Engineering

## Reliability Defaults

- Prefer explicit error handling and non-zero exits for automation.
- Prefer readable files over hidden storage layers.
- Keep workflow changes aligned with validation and Git checkpoints.
- Prefer generated indexes over scattered manual lists when the source of truth is on disk.

## Review Heuristics

- Prioritize regressions and routing ambiguity over style.
- Keep runbooks and command surfaces current with implementation.
- Keep modules small and composable.
